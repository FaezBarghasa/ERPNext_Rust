# erp-learning

Course syllabi, student enrollments, lesson tracking, and automated quiz evaluation engines.

---

## 📦 Overview

`erp-learning` powers training management, LMS course structures, and student grading for `rust-web-land` (`rwl`).

### Key Capabilities

- **LMS Engine (`lms.rs`)**: Modular courses, lessons, progress markers, and grading logic.

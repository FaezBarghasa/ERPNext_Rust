# erp-hr

Employee directory, shift attendance logs, salary structures, statutory deductions, and automated payroll batches.

---

## 📦 Overview

`erp-hr` provides human resource management and payroll computation adhering to statutory earnings and deductions.

### Key Capabilities

- **Attendance Tracking (`attendance.rs`)**: Logs check-ins, calculates working hours, and validates shift rosters.
- **Payroll Computation (`payroll.rs`)**: Salary slip generation with custom components, tax deductions, and journal entry integration.

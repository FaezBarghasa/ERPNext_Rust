# ⚡ `rwl` — rust-web-land Unified CLI & 1-Click Launch Kit

The official command-line interface and standalone runner for **rust-web-land**, the pure-Rust enterprise no-code webapp substrate.

---

## 🛠️ Unified Commands

```bash
# 1. Initialize a new application from an industry blueprint
rwl init my-store --blueprint erp

# 2. Launch the visual builder studio
rwl studio --port 8080

# 3. Package an ultra-lean 1GB-RAM-budgeted deployment bundle
rwl export --target vps --output ./deploy

# 4. Deploy incremental zero-downtime updates to a live production VPS
rwl deploy --host 192.168.1.100 --port 8080 --token secret123

# 5. Run the standalone production server with embedded SurrealKV
rwl serve --port 8080 --host 0.0.0.0 --data-dir ./data/rwl.db

# 6. Display runtime resource envelope and health status
rwl status
```

# erp-lending

Loan disbursements, compounding interest accruals, and precision amortization schedules.

---

## 📦 Overview

`erp-lending` delivers precision financial calculations for loan portfolios, repayment schedules, and interest accounting.

### Key Capabilities

- **Amortization Engine (`amortization.rs`)**: Computes equal monthly installments (EMI), principal breakdown, and interest accruals.

# desk-components

Cross-platform UI components, dynamic JSON-schema form renderers, grid layouts, and video HUD overlays for Desktop and Web.

---

## 📦 Overview

`desk-components` provides shared UI building blocks, reactive state adapters, and dynamic form generation for the ERPNext Rust client layer.

### Key Capabilities

- **Dynamic Form Engine (`forms.rs`, `form_engine/`)**: Declarative JSON-schema driven form generator rendering inputs, selectors, and validation errors.
- **Grid Layouts (`grid.rs`)**: Data tables with sortable columns and pagination.
- **Signals & Reactive State (`signals.rs`)**: State containers for real-time reactivity.
- **Video HUD (`video_hud.rs`)**: Overlay controls and player HUD for multimedia workflows.
